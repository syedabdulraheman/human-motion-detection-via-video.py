\# Human Motion Detection via Video



This project leverages \*\*MediaPipe Pose\*\* and \*\*OpenCV\*\* to analyze human motion in videos. It detects and visualizes human body landmarks frame-by-frame, saving the processed video with overlaid pose skeletons.



\## Features



\- \*\*Pose Detection\*\*: Identifies key body landmarks in each video frame.

\- \*\*Motion Visualization\*\*: Draws pose skeletons to visualize movement.

\- \*\*Output Video\*\*: Saves the processed video with overlaid pose landmarks.

\- \*\*Customizable Input\*\*: Accepts user-defined video paths and output directories.
